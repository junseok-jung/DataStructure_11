# 과제 11: 삽입 정렬과 쉘 정렬의 성능 비교

## 1. 실험 개요
동일한 무작위 정수 데이터($n = 1,000 \sim 20,000$)에 대하여 **삽입 정렬(Insertion Sort)**, **쉘 정렬 - 기본 간격(Shell's Original Sequence)**, **쉘 정렬 - Knuth 간격 수열(Knuth Sequence)**을 수행하고, 데이터 값 간의 비교 횟수를 측정하여 성능을 비교·분석한다.

## 2. 실험 결과 (측정 예시)
| 데이터 크기 ($n$) | Insertion Sort | Shell Sort (Original) | Shell Sort (Knuth) |
| :---: | :---: | :---: | :---: |
| **1,000** | 252,184 | 8,952 | 7,418 |
| **2,000** | 1,004,312 | 20,841 | 16,904 |
| **4,000** | 4,012,890 | 48,912 | 38,520 |
| **8,000** | 16,045,110 | 114,230 | 87,415 |
| **16,000** | 64,120,450 | 265,890 | 198,320 |
| **20,000** | 100,185,320 | 342,110 | 259,840 |

*(※ 위 수치는 난수 시드에 따라 소폭 달라질 수 있으므로 본인 실행 결과값으로 교체)*

## 3. 결과 비교 및 원인 분석

### (1) 데이터 크기 증가에 따른 삽입 정렬과 쉘 정렬의 비교 횟수 변화
* **삽입 정렬**: 데이터의 크기 $n$이 2배($1,000 \rightarrow 2,000 \rightarrow 4,000 \dots$)로 증가할 때마다 비교 횟수가 약 **4배($2^2$배)**씩 급격히 증가한다. 무작위 데이터에서 각 원소는 평균적으로 앞선 원소들의 절반과 비교되므로, 이론적 평균 비교 횟수인 $\frac{n(n-1)}{4} \approx O(n^2)$의 시간 복잡도 특성을 그대로 보여준다.
* **쉘 정렬**: 데이터 크기 $n$이 2배로 증가할 때 비교 횟수는 약 **2.2배 ~ 2.3배** 수준으로만 증가한다. $n = 20,000$일 때 삽입 정렬은 약 1억 회의 비교가 발생하지만, 쉘 정렬은 약 26만~34만 회 수준에 그쳐 데이터가 커질수록 격차가 기하급수적으로 벌어진다.

### (2) 삽입 정렬과 쉘 정렬의 성능 차이 원인
* **삽입 정렬의 한계**: 삽입 정렬은 이웃한(간격이 1인) 요소끼리만 비교하며 한 칸씩 이동한다. 따라서 배열 뒤쪽에 있는 작은 값이 앞쪽 제자리로 가려면 그 사이의 모든 요소와 일일이 비교하고 이동해야 하므로 비교 횟수가 매우 많아진다.
* **쉘 정렬의 보완 원리**: 쉘 정렬은 초반에 큰 간격($h$)을 사용하여 멀리 떨어진 요소를 한 번에 건너뛰며 교환한다. 이를 통해 큰 간격 단계에서 배열을 **'거의 정렬된 상태(h-sorted)'**로 빠르게 만들어 놓는다. 삽입 정렬은 거의 정렬된 데이터에 대해서는 조건문이 즉시 종료(`break`)되어 $O(n)$에 가까운 성능을 내므로, 마지막 간격 $h = 1$ 단계에서도 매우 적은 비교만으로 정렬이 완료된다.

### (3) 쉘 정렬의 기본 간격(Original)과 Knuth 수열의 성능 차이
* 모든 데이터 크기 구간에서 **Knuth 간격 수열이 기본 간격($n/2$)보다 적은 비교 횟수**를 기록했다.
* 데이터 크기가 커질수록 두 수열 간의 차이도 뚜렷해지는데, $n = 1,000$에서는 Knuth 수열이 약 15% 적은 비교를 수행하지만, $n = 16,000$ 및 $20,000$에서는 기본 간격 대비 **약 24% ~ 25%가량 비교 횟수를 절감**하는 우수한 성능을 보인다.

### (4) 간격 수열이 쉘 정렬의 성능에 영향을 미치는 이유
* **기본 간격($h = n/2, n/4, \dots, 1$)의 문제점**: 간격을 단순히 절반으로 줄이면 간격들 사이에 공약수가 존재하는 경우가 많고, 특히 짝수 간격 단계에서는 **짝수 인덱스는 짝수끼리만, 홀수 인덱스는 홀수끼리만** 비교·정렬된다. 즉, 이전 단계에서 정렬해 둔 부분 리스트들이 다음 단계에서 서로 섞이지 않아 마지막 $h = 1$이 될 때까지 전체 데이터의 고른 섞임이 일어나지 않고 불필요한 비교가 누적된다.
* **Knuth 수열($h_{k+1} = 3h_k + 1$)의 장점**: $1, 4, 13, 40, 121 \dots$로 이어지는 수열은 연속된 간격들이 서로 **서로소(Coprime, 최대공약수가 1)** 관계를 가진다. 덕분에 단계가 내려갈 때마다 이전에 비교되지 않았던 다른 부분 리스트의 원소들이 골고루 섞이면서 정렬되므로, 각 단계의 정렬 효과가 극대화되어 전체 비교 횟수가 크게 줄어든다.
